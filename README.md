## 📁 Phase 1: MySQL Basics

`Directory: MySQL/01 Basics/`

Below is a breakdown of the foundational concepts covered in this phase. Each file builds directly upon the previous one, simulating a live database development workflow.

| File Name | Core Concept | Description |
| :--- | :--- | :--- |
| `01 Working-with-Data.sql` | Intro to Data Basics | Understanding foundational data structures and how SQL interacts with information. |
| `02 Create-Database.sql` | Schema Management | Learning how to properly initialize, configure, and drop database environments. |
| `03 Create-Table.sql` | Table Architecture | Designing structured tables, defining columns, and setting basic constraints. |
| `04 Inserting-Data.sql` | Data Population | Populating existing database tables safely with single and multi-row records. |
| `05 Select-Data.sql` | Data Retrieval | Fetching and reading targeted information using fundamental `SELECT` queries. |
| `06 Sorting-Data.sql` | Data Organization | Ordering query results systematically in ascending or descending order using `ORDER BY`. |
| `07 Limiting-Data.sql` | Row Constraints | Managing large datasets efficiently by restricting output sizes using the `LIMIT` clause. |
| `08 ASsign-Data.sql` | Assign / Alias Data | Improving query readability by temporarily renaming columns or tables using the `AS` keyword. |
